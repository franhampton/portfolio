How it works

  • Searches the calendar by keyword. It looks for PTO, paid time off, vacation, out of office, OOO and doctor appointments from 90 days back to a year ahead.
  • Filters out false matches. Outlook search is fuzzy and can return unrelated meetings, so every result is checked against an exact list of phrases before it appears.
  • Respects Microsoft's limits. Outlook rejects too many calendar requests at once, so the searches run one at a time and the dashboard fills in as each one finishes.
  • Keeps working if a search fails. One slow or failed search doesn't block the rest. The dashboard shows what it found and flags what to reload.

Built with Claude and the Microsoft 365 connector. Names and events on this page are fictional.
